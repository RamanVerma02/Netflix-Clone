# 🎬 Netflix UI Clone (HTML & CSS)

A **responsive Netflix UI clone** built using **pure HTML and CSS**.  
This project was created for **practice and learning purposes** to understand layout structuring, responsiveness, and modern UI design.

🔗 **Live Demo:**  
👉https://ramanverma02.github.io/Netflix-Clone/

---

## ✨ Features

- Responsive Netflix-style homepage
- Modern UI layout
- Hero section with call-to-action
- Movie / show card sections
- Footer with multiple links
- Mobile-friendly design
- No frameworks used (Pure HTML & CSS)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Flexbox
- Responsive Web Design
